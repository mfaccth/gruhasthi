## Household Automation

An Android App that helps with the grind of daily routines using Automation. This App will also be eventally be released for iOS devices.

### Core Functions
The App will support the following features to begin with:
1. Creating Grocery Lists and sending these lists to a neighbourhood store that delivers
2. Making Payments to a contact in the Contacts List supported by the App

### Support Functions
To support the two primary functions above, the App should support:
1. Contact List. Users should be able to add new contacts. 
2. List of neighbourhood stores. The App will support creating a separate Grocery list for each store using two modes:
   - Directly adding details of a new store
   - Using Web Search to locate neighbourhood stores that delivery and adding them to the list of neighbourhood stores

### Voice Support
The App will be primarily operated by Voice. 
- App will provide a "Tap to speak" facility.
  - Users can request sending of Grocery lists to the respective store, using WhatsApp. 
  - Users should also be able to requests payments to these stores using Google Pay UPI to begin with. The request may or may not have info about the payment amount
  - Users should also be able to request payments to contacts.  The request may or may not have info about the payment amount

### Data Storage
Data should be stored locally on the mobile device.

### User Interface
The primary colours should be shades of Pastel Pink and Pastel Light Yellow. A centered microphone with the different features arranged around the microphone in a arc above the microphone
